# ♞ Chess

A clean, offline, single-page chess game. No frameworks, no build step, no images — just open `index.html`.

**Created by Dayanithi**

## Features

- Full chess rules: castling, en passant, promotion (with piece picker)
- Check, checkmate, stalemate, fifty-move rule, threefold repetition, insufficient material
- 2-player mode or **vs Computer** (Easy / Normal / Hard / Pro)
- Turn indicator, red highlight on captures
- Legal-move hints, last-move highlight, check highlight
- Move list in standard algebraic notation, captured pieces
- Undo, flip board, copy FEN
- Responsive, dark aesthetic UI that works on desktop and mobile

## Run

```bash
# just open the file
open index.html
```

## Files

| File | Purpose |
|------|---------|
